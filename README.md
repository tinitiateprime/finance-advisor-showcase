# FinAdvisor — Multi-Theme Financial Advisor Platform

## Quick Start
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Features
- 3 selectable layout themes (Dark, Light, Gradient)
- Fully responsive — mobile, tablet, desktop
- Hamburger menu on mobile for all themes
- Collapsible sidebar on mobile (Dark Dashboard)
- AI chatbot on every page (floating FAB, bottom-right)
- ApexCharts: Area + Donut charts
- Breadcrumb navigation with back-to-themes button

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- react-apexcharts
